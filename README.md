\# Estimator Harga Mobil Bekas



Prototipe edukatif prediksi harga jual mobil bekas (regresi) untuk Tugas Besar Praktikum Pembelajaran Mesin, Prodi S1 Sistem Informasi, Universitas Bengkulu.



> \*\*Disclaimer Akademik:\*\* Sistem ini adalah prototipe edukatif dan bukan penentu keputusan profesional nyata.



\## Menjalankan



```bash

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

cd backend

uvicorn app:app --reload

```



Buka `http://127.0.0.1:8000`.



Dokumentasi lengkap ada di folder root: ARCHITECTURE.md, PRD.md, DESIGN.md, dan HANDOFF.md.
